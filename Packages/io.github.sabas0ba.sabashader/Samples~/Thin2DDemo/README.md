# Thin2D Demo

同じ 3D メッシュ `Meshes/Sculpture.asset` に、通常の Standard、Paper2D、Acrylic2D の Material を適用して比較するシーンです。背後の縦線は輪郭と白い余白の見え方を確認するための基準です。

## 開き方

1. Package Manager で SabaShader の **Thin2D Demo** を Import します。
2. `Thin2DDemo.unity` を開きます。
3. 右上の紙または下段のアクリルを選択し、Material の `ローカル Z の厚み` (`_DepthScale`) を変更してください。`1` は元の奥行き、`0.18` はサンプルの薄い状態です。Scene ビューで横から見ると差を確認できます。

Paper2D は段階的な陰影、粒状感、3D メッシュの輪郭線を組み合わせます。Acrylic2D は紙状の印刷色の上にアクリル層を合成します。両方に白い外縁があり、Material の `白い余白の幅` で調整できます。Acrylic2D の `擬似厚み`、`印刷面の屈折`、`屈折スケール`、`内部散乱光` を調整すると、正面から見た印刷面と斜めから見たアクリル面の差を確認できます。右下のアクリルは `表面の影` をオフにした例です。

厚みの圧縮は各 Renderer のローカル Z 軸を基準にします。複数部品を一体として薄くする場合は、このサンプルのようにメッシュを結合するか、部品の配置も調整してください。`表面の影` と `投影影` は個別に切り替えられます。アクリル層は印刷面へ合成してから不透明描画するため、重なった面で二重合成されません。

このシーンは Unity 2022.3 の Built-in Render Pipeline で作成しています。
